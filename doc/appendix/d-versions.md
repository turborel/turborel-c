# Appendix D: Versions

[Contents](README.md)

The driver's version is the turborel release it is made for, the same number as the server's. This alpha is 0.0.0, as turborel's is, and speaks the native protocol's version 1. `trl_version()` gives it ([Versions](../client/01-version.md)), and [VERSIONING.md](../../VERSIONING.md) says how releases are published.
